## Initial Definitions

1. **Totality of Presence** - each **Point** or **Shape** *P* in a **Space** *S* with *N* **Dimensions** has exactly *N* **Scalar Coordinates**. 
    * Where a **Point** or **Shape** within a **Space** is assumed to be *fully present* (understood **Coordinate**, **Point**-wise) within it.
1. **Holographic Principle** - where the **State** or **Information** of a spatial system with *N* **Dimensions** can be entirely encoded within a spatial system with *M* **Dimensions** such that *M* < *N*.
1. **Holographic Shadow** - a spatial object (**Point**, **Hyperplane**, or **Shape**) that either violates the **Holographic Principle** or the **Totality of Presence**.
    * E.g. - a spatial object that exists in *M* **Dimensions** but not *N*, *O* **Dimensions** but not *P* (where *M* < *N* < *O* < *P*).
    * E.g. - a spatial object situated within a *N* **Dimensional Space** that has fewer than *N* **Scalar Coordinates**.
1. **Float/Real Attachment** (**Leibnizian Attachment**) - a **Model** *M* that satisifies **Leibnizian Termination** and **Continuity** is a **Model** for the **Integral Calculus**.
1. **Fuzzy Set Theory** - a **Set Theory** where the **Elemental Inclusion Operator** is mapped to the inclusive interval `[0,1]`.
    * Where an **Element** or **Set** can be a partial member of a **Set**.
1. **Fuzzy Topological Spaces** - a **Topological Space** that's defined and built up using **Fuzzy Set Theory**.
1. **Chiastic Sequence**
    * See LaTeX definitions for **Weak**, **Intermediate**, and **Strong**.
    * **Intermediate Sequences** are sufficient for complex orthagonal mappings supporting weak algebras and spatial relationships *within* the **Relation** *R*.
